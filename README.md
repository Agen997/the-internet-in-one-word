One word for the whole internet: **clickbait**.

Every headline, thumbnail, notification and "you won't believe" teaser on the
internet exists to make you click. The internet is not a library — it is a
lure.

`main.py` writes the single word to `/output/entry.txt` (UTF-8, 9 characters,
one word, no trailing newline).
